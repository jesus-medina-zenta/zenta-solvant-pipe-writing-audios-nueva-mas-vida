# Versión 1.0.0

## Descripción

Versión estable del repositorio **znt-template-pipe-python**.

### Características principales:
- Arquitectura modular y escalable para pipelines ETL en Python.
- Compatibilidad con Python 3.12+, Pydantic v2 y async/await.
- Integración lista para Google Cloud Run Jobs y BigQuery.
- Logging estructurado, métricas y trazabilidad.
- Dockerfile multistage y CI/CD con Cloud Build.
- Suite completa de tests automatizados (23/23 tests pasando).
- Ejemplos listos para usar y scripts de automatización.
- Seguridad y buenas prácticas DevOps.

Esta versión es la base recomendada para nuevos pipelines de datos en ZENTA.
